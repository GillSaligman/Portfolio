Modular Robotic Arm System

Senior Design Project | Drexel University

Overview

Inspired by NASA's RASC-AL competition, I led a team to develop a modular robotic arm system with distributed control architecture. The design emphasizes adaptability, repairability, and upgradeability with a streamlined four-wire backbone (HV+/-, LV+/-) enabling hot-swappable joints.

This prototype serves as a hands-on test platform to validate modular architecture and distributed control concepts. While not designed for actual lunar missions, the system demonstrates essential characteristics for sustainable robotics in challenging environments:

Core Innovations

  • Radical Modularity: Only four wires power all joints, drastically reducing wiring complexity
  • Independent Joint Controllers: Each joint contains its own electronics package for hot-swappability
  • Distributed Intelligence: Joints operate autonomously with local PID control

Key Capabilities

  • Component-level repairability without system shutdown
  • Future-proof design allowing technology upgrades
  • Redundancy through independent joint controllers
  • Simplified troubleshooting and maintenance

Project Highlights

As project lead, I personally executed mechanical design, electrical systems, firmware development, prototyping, and validation testing while coordinating documentation and outreach.

Concept Selection

We evaluated four approaches against NASA RASC-AL criteria:

  • Multi-functional robot with multiple arms
  • Specialized single-task robot
  • Swarm of specialized robots
  • Modular swarm with interchangeable attachments

Design Decision

The modular robotic arm approach was selected for its:

  • Long-term serviceability in isolated environments
  • Scalability through interchangeable components
  • Adaptability to evolving mission requirements
  • Cost-effectiveness through 3D-printed parts

Implementation Strategy

  • ROS 2 integration for realistic deployment simulation
  • MQTT communication for distributed control
  • End-to-end validation of autonomous capabilities

Mechanical Design

I engineered the robotic arm from concept to implementation, performing singularity analysis, torque/payload calculations, and iterative prototyping for each joint.

Structural Design

  • 1"x1" aluminum backbone for structural rigidity
  • Independently mounted 3D-printed joints
  • Material selection based on functional requirements:
    • PLA for non-critical components
    • PETG for impact resistance
    • ABS for high-stress gears (with thermal expansion compensation)

Motion Systems

  • Polulu 24V DC motors with 150:1 gearboxes
  • Cost-effective potentiometers for position feedback
  • Custom regression analysis for angle calibration
  • Motor selection based on pre-emptive torque calculations

Key Solutions

  • Clamping mechanism for ABS components to prevent thermal warping
  • Integrated cable routing through hollow joints
  • Modular mounting system for rapid reconfiguration

Design Objectives

  • 200% torque increase over direct drive
  • Near-zero backlash operation
  • Fully 3D-printed implementation

Technical Implementation

  • Precision elliptical wave generator
  • Flex spline with optimized tooth profile
  • Circular spline with 2% more teeth than flex spline
  • Modular design for easy maintenance

Validation & Outcomes

  • Demonstrated feasibility of high-torque additive manufacturing
  • Achieved target torque increase in bench testing
  • Time constraints prevented full system integration

Design Challenges

  • Requirement for 600° rotation range
  • Limited 270° range of standard potentiometers
  • Axial loading constraints
  • Internal wiring requirements for gripper

Innovative Solutions

  • 4:1 potentiometer gearing for expanded range
  • Combined thrust and radial bearing system
  • Hollow core design for internal wiring
  • Servo-driven parallel-jaw gripper

Performance Characteristics

  • 120° gripper range of motion
  • Interchangeable jaw system
  • Integrated force sensing via current monitoring

Electronics

The electronic system features a shared four-wire backbone (HV+/- and LV+/-) powering independent joint controllers, enabling modular expansion without system reconfiguration.

Component Selection Process

  • Tested 8+ microcontrollers for optimal performance
  • Selection criteria:
    • MicroPython compatibility
    • Analog input resolution
    • Wi-Fi stability under load
    • PID execution capability
  • ESP8266 selected after rigorous validation

Joint Electronics Package

  • ESP8266 microcontroller
  • Precision potentiometer for position feedback
  • Motor driver with current-limiting protection
  • DC gearmotor with thermal monitoring

Advanced Features

  • Automatic Wi-Fi reconnection routines
  • Soft and hard motor current limits
  • Temperature monitoring with thermal derating
  • Local PID execution at 100Hz

Power Management

  • 24V/12V dual-rail power supplies
  • High-efficiency (92%) DC-DC buck converters
  • Polyfuse protection on all circuits
  • Redundant power pathways

Control Systems

  • Raspberry Pi 4B central controller
  • Dual-band Wi-Fi with Ethernet failover
  • Dedicated cooling solution
  • Real-time system monitoring

Design for Serviceability

  • Color-coded wiring harnesses
  • Hot-swappable power modules
  • Diagnostic LEDs on critical circuits
  • Modular component arrangement

Software & Communication

Distributed architecture uses a Raspberry Pi-hosted network managing MQTT communication across all joints, supporting position and velocity control modes with real-time telemetry.

MQTT Implementation

  • Structured bracket system: [DR, DL, J3, J4, J5, J6, J7]
  • Three data types:
    • Controller Data: Xbox inputs → normalized velocities
    • Desired Commands: P[angle] or V[value]
    • Actual Data: Real-time joint positions
  • 10Hz update rate for real-time control

Control Modes

  • Velocity Mode:
    • Direct joystick-to-motor mapping
    • Example command: V0.75 (75% max speed)
  • Position Mode:
    • Joint angle specification
    • Example command: P45.00 (45° position)

Data Handling

  • Timestamped position reporting
  • Error code propagation
  • System status monitoring

Network Infrastructure

  • hostapd for Wi-Fi access point
  • dnsmasq for DHCP services
  • Mosquitto MQTT broker
  • Secure SSH access

Control Workflow

  1. User connects to robot's Wi-Fi network
  2. SSH into Raspberry Pi
  3. Launch control scripts
  4. Select operation mode (velocity/position)
  5. Initiate control via Xbox controller or direct commands

System Management

  • ROS 2 integration for simulation
  • Web-based dashboard (Flask)
  • Automatic error recovery routines
  • System diagnostics and logging

Startup Sequence

  1. Automatic Wi-Fi connection with fallback
  2. MQTT topic subscription
  3. Self-calibration routine
  4. Position initialization

Real-Time Processing

  • Bracket command parsing
  • Potentiometer to angle conversion via regression
  • PID control loop execution at 100Hz
  • Velocity trapezoidal profiling

Safety Systems

  • Software limit switches
  • Over-current protection
  • Watchdog timer reset
  • Thermal shutdown protocol
  • Emergency stop handling

Prototyping & Assembly

Reverse assembly approach enabled independent validation of each joint, preventing integration complexities and accelerating development.

Assembly Process

  1. Began with end-effector (gripper) development
  2. Progressed backward through joints (J6 → J5 → J4 → J3)
  3. Validated each subsystem independently
  4. Integrated wiring at each stage

Software Integration

  • Pre-flashed firmware for all joints
  • Automated PID tuning scripts
  • Continuous integration testing
  • Modular communication architecture

Validation Approach

  • Early testing of most complex components
  • Progressive weight testing as joints added
  • End-to-end communication validation
  • Real-world task simulation
